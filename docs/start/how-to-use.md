# How to use this wiki

Each system page starts with a plain-language explanation, then moves into operation, diagnosis, and technical detail. Read only as far as the job requires.

## Choose your depth

- **Understand:** Learn what the system does and the words used to discuss it.
- **Operate:** Know what normal behavior looks like and how to work safely.
- **Diagnose:** Test from observations before replacing parts or changing code.
- **Specialize:** Work through design tradeoffs, control behavior, interfaces, and implementation patterns.

## Improve a page

Write for more than one season. If a past robot is useful, label it as an example. Name the vendor, software version, or rule set when the advice depends on one.

The [Wiki essentials](../wiki-essentials/) section explains how to edit or add pages, use Markdown and diagrams, preview changes, and publish through a pull request.
