# Pit workflow

Pit work happens under time pressure. Use the same basic sequence each time, make ownership clear, and do not let several people make untracked changes at once.

## Triage sequence

1. Make the robot safe.
2. Capture symptoms and fault indicators.
3. Check power, communication, and physical condition.
4. Reproduce the smallest safe version of the problem.
5. Change one relevant variable.
6. Retest and record the result.

## Hand off clearly

State what happened, what was observed, what changed, and what still needs verification. Avoid passing along only a suspected cause.
