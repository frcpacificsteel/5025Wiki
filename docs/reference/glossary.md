# Glossary

## CAN

Controller Area Network, the shared communication bus commonly used by robot controllers, motor controllers, sensors, and power devices.

## Command

A unit of robot behavior that requests subsystem capabilities and defines when the behavior ends or is interrupted.

## Feedforward

A calculated output based on the expected effort required to produce motion, before considering measured error.

## Feedback control

A controller that adjusts output using the difference between a target and a measurement.

## Kinematics

The mathematical relationship between the motion of a robot and the motion of its individual parts.

## Telemetry

Measurements, states, events, and faults published so robot behavior can be observed and analyzed.
